✅ CSRF Token Flow
   Laravel (/sanctum/csrf-cookie)
      ↓
   Express (stored in session)
      ↓
   React (request interceptor attaches to header)
      ↓
   Every request includes: X-CSRF-TOKEN header

✅ Bearer Token Authentication
   Login Response → token
      ↓
   React localStorage storage
      ↓
   Request interceptor attaches to Authorization header
      ↓
   Every authenticated request: Authorization: Bearer {token}

✅ Protected Routes
   No token → 401 Unauthorized
      ↓
   Response interceptor catches 401
      ↓
   Clear localStorage
      ↓
   Redirect to /login
